# E05 最小修复计划

1. 新增独立拒绝层：不修改 B、Δ、Final，不重新生成或删除断言，不改变原 engine。语义输出仅为候选 `PASS/REJECT/UNKNOWN`，告警安全裁决恒为空。
2. 复用哈希固定的 E01 简单 C 条件规范化器，增加零/非零两值真值表检查 `Not/And/Or`，拒绝相反方向、恒真弱化与恒假候选。结构解析使用 E02，不调用 SMT。
3. 从保存的源码绑定函数、词法作用域、显式声明位置、类型、表达式结构及 SHA-256，构造不同身份。不猜 typedef、成员定义、别名关系。仅支持指针/整数 zero-test 与 Bool 测试，不批准一般 C 算术建模。
4. 检查直白单语句分支和紧邻的无条件 return 后路径。复杂条件、宏、goto、绕行、干预语句以及未确认边方向诊断 UNKNOWN。更大历史函数仅提供局部证据，完整上下文仍 UNKNOWN。
5. 对源码简单 +/- 赋值与模型等式做结构核对：成员叶子被替换成其指针根且其余表达式一致时，报告局部身份破坏；不证明该赋值状态能传播到目标，不填成员类型。
6. 原 E02/E03 B+Δ 检查保持独立、只读；语义通过不能覆盖结构失败，结构通过不能覆盖语义拒绝/不确定。
7. 先合成测试；冻结实现、配置、测试及历史输入哈希；再回放 10 审计样本和 E04-ND，最后只检查一次固定 20。固定集不是盲测集，不根据结果调参。
