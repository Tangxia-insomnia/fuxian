## 2. 支持范围与接口

参数入口有 @0；可识别初始化/赋值各建不可变的新版本。每个版本保留 dataset/position、函数和声明身份、slot、前一版本、定义事件、赋值原文/源范围、类型、来源版本、path、body/source SHA 和诊断。名称只用于显示，不能构造身份。

`q=p` 保存对旧 p 版本的值复制关系；之后 p 更新不改变 q 的记录。它不证明两个 slot 是同一个变量，也不证明所指内存对象、内容或生命周期。读取只能绑定当前路径上的可靠定义。

受限 if 的两条语法路径独立延续，保留 guard 原文/方向/读取 ID；不证明路径可满足性，不取反、不生成约束、不推断指针非空。return 仅终止本地路径。调用前简单实参读取可单独有证据，整次调用仍为 UNKNOWN：所有调用都是效果边界。复杂/副作用实参先整体拒绝，避免 C 未规定的实参求值顺序产生错误读取版本。

循环、goto、多 if、一般算术、unsigned 运算、宏、未知类型/转换、聚合体复制、间接/成员/数组写、取址逃逸、volatile/atomic、全局/静态状态和复杂调用等均不能获得完整 PASS。未知效果使当前环境失效并停止路径，旧记录保留。未知调用返回值可存 UNKNOWN 新事件，不能据此继续传播。

类型/声明 PASS 只限受控自包含 C TU、无预处理及 warning/error 的支持子集。本轮没有把保存的内核/第三方函数片段包装成虚构的完整 TU；没有注入宏、typedef、头文件、cast 或构建配置。
