推荐分 **5 轮** 实现，每轮需单独授权。当前只完成设计，不启动 R01。保持论文/官方冻结版本、现有单 Agent 和全部历史基线；不从零重写通用 C 分析器。各轮默认先做离线检查，不预授权模型 API、Z3、全量实验或生产接入。

## 0. 每轮共同的实验程序

1. 创建独立新目录，固定 Git 状态、核心/历史/账本哈希、输入及范围。缺失来源、保护校验失败、意外 live 调用即停止。
2. 先写支持语法/类型/路径/效果清单及预期负例；未知情况不能靠减少 UNKNOWN 达标。
3. 使用明确标为合成的自包含 C 输入验证通用逻辑。所有预期 PASS/REJECT/UNKNOWN 都逐项核对；不使用真实样本 ID 分支。
4. 检查指定历史调试材料，保留失败/不支持项和源/模型原文，不修改缓存。
5. 冻结该轮候选、配置和输入哈希后，对原 20 条固定回归材料只做一次该轮范围内的离线检查。保留所有 20 条，不改顺序、不替换样本、不把它称为盲测。发现问题则记录/停止该候选，不能反复调整后仍报告为同一次独立验证。
6. 按检查阶段分别计数：源证据可用、调用绑定、状态、效果、路径、B+Δ 保留，以及未尝试/不适用。UNKNOWN 不计成功；局部 PASS 不作为完整语义覆盖或过滤数。
7. 最终重新核对保护和预算账本，提交本轮报告，等待下一轮决定。任何安全策略接入/模型/求解实验都需另设范围和预算。

本设计审查已经接触并筛选了固定集，后续也不能称其未接触。原 10 条审计样本、A01/A04、E04-ND 继续作调试和风险哨兵，不新抽样替换。

## R01：直接调用与入口实参/形参关系

**优先级最高。** 开发前先验证现有 libclang 的加载与可重复的诊断读取，只对有足够声明、无宏、无解析错误的自包含输入批准 AST 身份；若不满足则停止，不安装/升级全部依赖。

首轮范围：已解析为直接 CallExpr 的唯一 callee；参数数目/序号/已知兼容类型；标识符实参和按值入口绑定。内建简单标量与已证明声明身份的 opaque struct 指针可作为候选；varargs、函数指针、宏调用、聚合体按值复制、复杂 casts 暂不支持。没有达到精确类型证据时，连局部映射也 UNKNOWN。

交付：CallEdge 与参数映射证据，caller slot 与 callee slot 保持不同，记录 entry/current value，不追踪函数体内写入或跨函数求解。

真实候选：固定序号 17 的 `sock_confirm_neigh(n)` 到 `neigh_confirm(n)` 边优先；固定序号 12 的 ast→st 序号对应备用；A04 仅作 char*→const void* 转换/证据不足负例。不能以类型拼写相同替代声明证明。

验收：参数乱序/重复候选/缺定义/错类型/间接调用全部按预期拒绝或 UNKNOWN；同名 callee 参数不合并 slot；每个批准边都有源范围、body/build证据状态和位置绑定；不输出任何跨函数路径/告警结论。

## R02：局部 def-use 与变量版本

范围：简单直线赋值、已知类型标量/指针值复制、受限单一 if/return；不实现一般 SSA。每个写入生成新版本，读取绑定该路径的 reaching definition；分支先保持不同环境。

正向合成：初始化 p0、赋值 p1、检查 p1；q=p_current 后 p 更新，q 仍为旧值；同名不同 scope 不串状态。未知返回调用可记录新结果版本，但其效果/返回性质未证明时不形成完整调用 PASS。

真实哨兵：E04-ND 第 185 行 skb_prev 与后续 skb 重赋值；A01 copied 的多次更新。其复杂 CFG/类型缺口仍允许 UNKNOWN，不能为“多一个 PASS”截去真实代码。

验收：旧版本所有约束保留且不误作用新版本；同路径读取唯一绑定；合流/未知写入/调用副作用缺失不得选择任一版本；unsigned 运算不假装数学 Int 已忠实建模。

## R03：纯/受限函数返回值与跨帧值关系

范围：完整可见、无外部未知调用/间接写/全局写的受限 callee；返回参数、常量及简单无环路径。独立调用上下文，区分返回值被使用、忽略和未返回路径。不从名称推断 malloc、check、init 等效果。

交付：精确 pre→return 的路径化记录及 caller 接收的新版本，按值参数局部赋值不改变 caller slot。首先不缓存摘要，避免不同 P/callsite 串用。

真实候选：固定序号 1 中 callee 早退与 caller 忽略返回值的负向验证；其外部函数/typedef 证据不足时 UNKNOWN。现有 3 条多帧样本并没有一条本阶段已证明满足完整“纯函数”正向条件，不能伪造成功。

验收：返回值映射、调用上下文和所有支持的返回路径都有来源；不把 callee 的 return 当 caller return；同名局部符号在不同调用实例不串用；未知效果或缺路径阻断完整摘要 PASS。

## R04：限定的间接写入和副作用

范围只从 `&local_slot` → 明确参数 → 单次 `*param = known_value` 开始，要求无逃逸、唯一指向、完整可见受限函数体。先以“传入另一个已知指针值并写入 slot”的合成程序验收；`*p=malloc(...)` 在缺分配模型时只能追踪未知新值，不认定非空或已完整恢复。

交付：读/写 footprint、显式别名证据、调用前后 memory/value version；未覆盖效果单独列出。全局变量、回调、未知库调用、任意多级指针和动态 points-to 不进入首版支持集。

真实哨兵：A04 的 clone/saved_clone 复制与 `strsep(&clone)`；E04-ND 的 `&maxfraglen` 和重分配。缺被调方效果时应 UNKNOWN，不能按函数名自动传播。

验收：唯一地址写入正确更新 caller 当前 slot；callee 只重绑按值参数不更新 caller；alias 不确定、可能写全局/共享内存或 effect footprint 不完整时阻断；旧内存版本约束不删除。

## R05：路径条件与跨函数组合契约

范围：前几轮已批准的边、状态和效果，在无环、预算内路径上组合 CallerPre、entry transfer、callee path 与 return/post。先做 IR 离线诊断；不在同轮默认接入原模型或 Z3。

交付：路径和调用上下文隔离的 ConstraintLedger，包含所有原 B/Δ 引用、传播关系与源位置；原 E02/E03 同帧契约照常保留。任何版本化派生表示需额外逐 atom 映射验证，不能让原结构 PASS 替代新语义合同。

真实候选：固定序号 12 同一个 read_index 的两个调用点；序号 17 嵌套条件与宏边界；序号 1 的早退/忽略返回值。完整样本在宏/类型/效果缺失时继续 UNKNOWN。

验收：不同路径不无条件合取；callee/调用方早退作用域正确；入口条件不被下层重新提取覆盖；原 B、Δ 不丢；超过路径/深度预算显式 UNKNOWN；整个过程不输出 FILTER。
