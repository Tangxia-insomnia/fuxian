# E06 安全验收与合成测试设计

**本文件全部为未来测试规格；本阶段测试执行数为 0，没有测试通过结果。** 合成输入应在后续授权轮次中另建文件，明确标注其合成性质，不作为真实漏洞证据。本设计不输出任何告警安全裁决。

## 1. 诊断协议

| 状态 | 定义 | 不代表什么 |
| --- | --- | --- |
| PASS | 对当前请求的某项局部传播关系，在支持范围内有完整证据且无冲突 | 不代表其他状态/效果已验证，不代表路径已不可行，更不赋予 FILTER 权限 |
| REJECT | 有明确证据显示候选映射、状态版本、类型或约束传递与事实冲突 | 是拒绝传播候选，不是判定该告警是真/假缺陷 |
| UNKNOWN | 来源、类型、路径、效果或语法等证据不足/超出范围 | 不得计为传播成功、误报过滤成功或已证明无风险 |

逐项保留 source_binding、argument_transfer、value_version、effect、path、structural_preservation 等状态。聚合时，有明确冲突报告 REJECT 并同时保留缺口；没有冲突但任一必需关系未验证则 UNKNOWN；只有全部必需检查有证据才允许该局部合同 PASS。不适用应说明未请求哪项检查，不能把 skipped 当成 PASS。

例如“识别 p 的新版本”可 PASS，同时“malloc 的完整效果”UNKNOWN；不得将前者替代后者输出整个调用传播 PASS。

## 2. 强制不变量

1. 原 B、Δ、历史模型文本及哈希不变，所有旧约束仍绑定其原时点；新增传播关系单独记录。无删除、弱化或按标签补约束。
2. 不把不同源码 slot 合为一个符号，不把旧值约束直接作用到新版本，不把 same-value 说成 same-slot/对象存活证明。
3. 每个批准调用边有唯一支持的 callee 绑定、参数序号、原文/范围、签名/转换和调用点上下文；每个当前值有唯一可验证定义。
4. 未覆盖效果、地址逃逸、全局/共享写入、不完整返回路径不能默认为无影响；宏/类型/CFG 不支持必须显式报告。
5. caller 前提、callee 入口、callee 路径和 caller post 分开。不同路径不无条件合取，callee 的 return 不充当 caller 的 return。
6. 约束来源追溯到原 source/atom 和版本；原 E02/E03 同帧结构检查不被新层绕过。派生版本 IR 与原字面公式的对应未证明时，不导出新的跨帧 SMT。
7. 不改变安全 v1，局部 PASS 没有 FILTER 接口。不得伪造 SAT/UNSAT 或用模型修复循环绕过语义拒绝。
8. 候选冻结、固定输入不变、固定 20 只检查一次；源码/配置缺失按缺口保留。保护失败、越界调用、历史被修改立即停止该候选。

## 3. 规划的合成测试矩阵

下表中的预期有明确前提：源码自包含、声明/位置/类型完整；若实际输入不满足前提，应改报 UNKNOWN 并说明，不能伪造这些前提。测试不得用 A01/A04 等 ID 作为分支。

| 编号 | 轮次 | 设计输入/现象 | 预期诊断及检查点 |
| --- | --- | --- | --- |
| M01 | R01 | 直接调用 f(p)，已知同类指针形参 item | 入口值映射 PASS；两个局部 slot 保持不同 |
| M02 | R01 | 两个不同实参被候选交换序号 | REJECT；指出调用位置、参数序号和不匹配关系 |
| M03 | R01 | 同名局部变量位于不同 scope/函数 | 各自绑定可 PASS；合并成一个 slot 的候选 REJECT |
| M04 | R01 | f(p,p)，两个参数位置明确 | 可建立两个独立形参值关系；不能因同值合并形参 slot；若候选只给名称无位置则 UNKNOWN |
| M05 | R01 | 实参/形参类型不同，候选忽略必要转换 | 错误的同类型宣称 REJECT；不支持的合法转换 UNKNOWN，不擅自插 cast |
| M06 | R01 | 缺少函数定义或有两个有效定义候选 | UNKNOWN，不按名称选第一个 |
| M07 | R01 | 函数指针/回调、宏名看起来像调用 | UNKNOWN；不能靠 token 形状批准为直接函数 |
| M08 | R01 | 聚合体按值、成员/复杂实参超出首轮 | UNKNOWN；保留完整表达式，不映射到根名字 |
| S01 | R02 | p0=NULL 后 p 获得一个新赋值值，再检查 p | 新定义 p1 和 guard 引用可 PASS；不把 p0 的 NULL 传播成 p1 的属性 |
| S02 | R02 | 候选将 p0 与 p1 合并并造成伪矛盾 | REJECT；原断言全保留，不为消除矛盾删 B |
| S03 | R02 | q=p，随后 p 更新 | q 绑定旧值；把 q 改成新 p 值的候选 REJECT |
| S04 | R02 | 相同标识符在 if 两边有不同赋值 | 分开 path/env；未支持合流时 UNKNOWN，不选最后文本赋值 |
| S05 | R02 | 循环/不明确 goto reaching definition | UNKNOWN，不伪造循环次数或 phi |
| S06 | R02 | unsigned 算术、未知 typedef 或位宽 | 不支持相关语义时 UNKNOWN；数学 Int 与原 C 类型不同不能自动 PASS |
| S07 | R02 | `skb->len` 的值被替换成指针 skb | 已绑定局部表达式冲突应 REJECT；缺成员类型同时保留 UNKNOWN 信息 |
| R01 | R03 | 完整纯函数返回形参或显式常量，caller 接收 | return→caller 新版本映射 PASS，保留路径/返回点 |
| R02 | R03 | callee 将按值形参重新绑定 NULL | 不改变 caller 的指针 slot；候选声称改变 caller 则 REJECT |
| R03 | R03 | callee 的 null 分支 return，caller 继续 use(p) | 不能据此推出 caller 后续 p 非空；错误传播 REJECT |
| R04 | R03 | caller 忽略 callee 返回值 | 记录“未接收”；不能擅自添加成功返回条件 |
| R05 | R03 | 一个函数多个 return 路径，只取其中一个摘要 | 完整摘要声明 REJECT/UNKNOWN（取决于是否明确冲突）；不漏掉其他支持路径 |
| R06 | R03 | 同一函数在两个 callsite 以不同参数/前提调用 | 上下文分离；跨上下文复用候选 REJECT；初期不做摘要缓存 |
| R07 | R03 | 函数名 malloc/alloc/check 但定义/模型缺失 | 不推断非空、纯函数或返回范围，完整传播 UNKNOWN |
| E01 | R04 | 唯一 caller slot 地址 `&p` 传入，callee 单次 `*pp=q` | 在完整受限条件下，p 获得来自 q 的新值，效果记录 PASS |
| E02 | R04 | 仅 `pp=q` 重绑形参本身 | 不写 caller 的 p；误写入候选 REJECT |
| E03 | R04 | 两个 pointer 值复制形成别名，再写被指内存 | 区分 slot 与 region；未实现内存别名时 UNKNOWN，不宣称“无影响” |
| E04 | R04 | 指针二级/成员地址无法唯一指向 caller slot | UNKNOWN；不根据 `**` 语法猜被改对象 |
| E05 | R04 | 已知 callee 全局写，但候选宣称无副作用 | REJECT；若定义/效果不完整则 UNKNOWN |
| E06 | R04 | `init(&p)` 内有未知分配调用/地址逃逸 | 新值事件可记；完整返回/内存效果 UNKNOWN，不默认分配成功 |
| E07 | R04 | realloc/free、悬垂对象与新分配可能同地址 | 缺生命周期模型则 UNKNOWN；地址相等不证明同一存活对象 |
| E08 | R04 | volatile/原子/并发共享状态 | UNKNOWN；普通局部版本不等于内存模型 |
| P01 | R05 | caller 非空早退假边，直接传参，callee 同值 guard | 前提和点/版本全部验证后局部传播可 PASS，不进行告警裁决 |
| P02 | R05 | caller 原前提在 callee 重新提取时被覆盖 | REJECT，CallerPre 原记录必须存在 |
| P03 | R05 | 两个互斥路径的约束被无条件相与 | REJECT；各路径独立账本/守卫 |
| P04 | R05 | callee 提前 return 和 callee 内 Sink 路径 | 仅把相应边作用于该 callee 的路径；不能作用到所有 caller 后续 |
| P05 | R05 | 跨帧同名 SMT 符号被直接合并 | 身份冲突 REJECT；缺原 atom 的版本映射则 UNKNOWN，不猜改名 |
| P06 | R05 | Final 丢 B 声明/断言或丢 Δ | 原 E02/E03 结构 FAIL；新层不能覆盖或自修正为 PASS |
| P07 | R05 | B+Δ 完整保留，但极性/成员/状态错误 | 结构 PASS 与语义 REJECT/UNKNOWN 同时保留，不晋升安全结论 |
| P08 | R05 | 缺宏配置、Clang recovery 类型或相关诊断 | UNKNOWN；不得自行 `-D` 后冒充原构建 |
| P09 | R05 | 超过路径/深度预算或递归 | UNKNOWN 并保留停止点；不把未探索分支删除 |
| P10 | 全轮 | 缺少 Source 状态 P 的证据，仅有 NULL 字符串/标签 | UNKNOWN；标签永不构造约束或前提 |

以上是 40 项测试规格，不是 40 项已执行结果。每项实际开发时还需记录适用轮次、输入字节/哈希、预期、逐步证据、实际诊断及耗时。测试生成的源码只能留在新轮次目录中，不修改历史真实源码。

## 4. 历史回归必须保留的结果

- A01：不能因新增状态机制而丢掉原 E01 的局部极性冲突；新前端不能擅自消除预处理缺口。完整语义未证明继续 UNKNOWN。
- A04：object/object_ptr/object_bv 的原诊断、B/Δ 缺失问题不得被“参数换名”洗成通过；clone/saved_clone 的赋值复制与地址副作用不靠名称推断。
- E04-ND：必须保留恒真弱化和成员替换诊断；185 行 skb_prev 不绑定后续重分配 skb；maxfraglen 调用前后未证明时 UNKNOWN。
- 固定 20：每轮全部保留；单帧/缺上下文样本不从分母消失。多帧候选也只按实际核验范围计数；不能把“5 条文本调用边被遍历”写成 5 条传播验证成功。

## 5. 指标及每轮放行条件

报告请求关系数、适用关系数、PASS/REJECT/UNKNOWN、缺证据/不支持原因、完整来源占比、状态版本冲突、参数/类型冲突、B/Δ 断言丢失、路径串用、效果未覆盖、离线耗时和保护结果。样本级和边/关系级分开统计，不把重复问题计成不同样本。

成功率同时给出 `PASS/全部请求关系` 和适用子集的口径，公开 UNKNOWN/不适用数，避免只报有利子集。对真实缺陷的操作保留率/误删率，本阶段及纯传播检查阶段均为未测；没有告警动作时不虚报 100%/0%。未来只有独立授权安全实验才能测这些指标，UNKNOWN 始终不能算过滤成功。

每轮需满足：全部已声明支持的正例和已知错误/缺口负例符合预期；保护校验通过；完整 B+Δ 留存；源码/版本/路径证据齐全；无 live 越界；固定结果如实保留；没有告警动作接口。真实历史覆盖率允许为 0，不能为放行而降低门槛。
