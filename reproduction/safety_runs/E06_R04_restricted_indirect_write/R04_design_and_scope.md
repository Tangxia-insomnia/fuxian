## 支持范围（实现前确定）

受控自包含 C11 TU，无预处理、warning/error 或不完整 AST。一个普通独立调用语句、恰好一个单级指针形参、一个直接 &caller 自动局部标量对象；该对象必须有可靠当前值版本。callee 唯一定义、void 正常返回、直线语法、最多一次 *原形参=简单定型 literal。允许单独 p=0 重绑以及写后 p=0；不会为 p=0 创建 caller 对象新版本。负数一元式、复杂 cast、一般表达式与局部 RHS 扩展均不支持。常量保存 Clang 类型/位宽/符号性、原文、转换和范围，不求数学整数值。

caller 复用 R02 直线赋值和单个 if，最多两条独立语法路径，以满足同 callsite 在不同路径的隔离检查；callee 不支持 if。最多16个调用实例。既无 phi，也无可满足性证明或 R05 组合。只允许当前 caller 局部变量的地址，参数对象、指针对象、成员、数组、union、static/extern/const/volatile/atomic、地址副本、函数指针、多级指针及不支持转换均 UNKNOWN。

callee 除单次直接写和字面0重绑原形参外，仅支持空语句、void return、嵌套普通语句块以及无效果的受支持只读表达式。新局部声明、其他调用、全局写、指针复制/运算/cast/返回/转传或任何未覆盖效果阻断。写前重绑后再解引用不能沿用入口目标。未知效果使 caller 的值环境及 memory-current 都失效，路径停止；之前识别的写入证据仍保留，但不提交 caller 后状态。

## 对象与版本

caller 词法局部对象 ID 由数据/源码/函数/声明/slot/body SHA 绑定，不随调用点变成另一个对象。各路径维护独立 memory-current；MemoryVersion 链连接当前 caller 值版本及实际写入事件。callee 指针 slot 位于 R03 call_context_id 实例 namespace，永远不等于 caller 标量 slot 或对象 ID。写入在 callee 中先记录，只有完整受限效果与正常返回均通过，才在 caller 生成新值及内存版本。后续 caller 本地赋值同样生成内存版本，旧记录不可变。

不做摘要缓存、通用别名、生命周期或重分配分析。这里的唯一性来自“新自动局部对象 + 无先前地址逃逸 + 直接 &对象 + 唯一参数 + 原参数未重绑 + 完整受限体”；不是动态 points-to 结果。
